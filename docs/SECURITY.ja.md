## 1. 100% 完全オフライン・ゼロクラウド流出
- **外部テレメトリの完全排除**:
  - 利用状況の収集、アナリティクス、クラッシュレポート送信、および外部クラウド API との通信は一切行いません。
- **ローカル限定 AI 通信**:
  - コード補完および対話チャット機能は、ローカルマシン上の Ollama デーモン（デフォルト: `http://127.0.0.1:11434`）とのみ通信を行います。
  - プロンプトやソースコードが外部ネットワークへ送信されることはありません。

---

## 2. パターン判定による機密ファイル除外ガード
開発者が機密情報を含むファイルを誤って AI モデルへ送信することを防ぐため、以下のファイル名パターンに合致するファイルを編集している間、AI 自動補完およびコンテキスト収集リクエストを自動遮断します：

- `.env*`（各種環境変数定義ファイル）
- 秘密鍵およびクレデンシャル（`id_rsa`, `id_ed25519`, `credentials`, `*.pem`, `*.key`, `*.keystore`, `*.jks`）
- パッケージマネージャ・クラウドアカウント設定（`.npmrc`, `.pypirc`, `kubeconfig`, `*.token`, `*secret*`, `.aws/credentials`, `.kube/config`）

## 3. 一時ファイル置換によるアトミック保存 (Atomic Safe Write)
- **破損防止の仕組み**:
  - ファイル保存時（および `~/.config/rooney/config.toml` の保存時）、既存ファイルを直接インプレースで切り詰めて書き込む方式は採用していません。
  - 対象ファイルと同じディレクトリに一時ファイル（`.{filename}.tmp.{pid}`）を作成し、コンテンツを書き込み後に OS の `sync_all` でディスクへの永続化を保証します。
  - 最後にアトミックな `rename` システムコールで置き換えるため、書き込み中の電源断やプロセス強制終了が発生しても、元のファイルが中途半端な破損状態になるリスクを極小化しています。

---

## 4. パストラバーサル防止 & ファイルシステム境界保護
- **ディレクトリ脱出サニタイズ**:
  - サイドバーからのファイル作成・ディレクトリ作成・リネーム処理において、相対パス記号（`..` や `/`）を用いた意図しないディレクトリ脱出をサニタイズ・検証します。
- **再帰的削除セーフガード**:
  - ルートディレクトリ（`/`）やユーザーホームディレクトリ（`~`）が誤って削除対象として指定されないよう、境界判定セーフガードを装備しています。
- **安全なパス解決**:
  - 設定ディレクトリやアイコン配置パスの解決には `directories::BaseDirs` を使用し、環境変数や symlink によるなりすましを防止します。

## 5. リソース保護 & Zero Remote I/O Markdown レンダリング

### Zero Remote I/O Markdown 原則
> **Markdown rendering performs zero remote I/O.**  
> Rooney の Markdown プレビュー処理は、外部リモート画像のフェッチ、スクリプト実行、外部ブラウザ起動、外部 HTTP/ネットワークアクセスを一切行いません。

- **画像構文の安全なテキストフォールバック**:
  - 画像構文（`![alt](url)` や `<img>` タグ）は外部からダウンロードせず、安全な軽量バッジ（`󰋩 [画像: alt]`）へインラインフォールバック描画します。
- **表示専用リンク**:
  - 意図せぬクリックによるフィッシングサイトへのブラウザ遷移を防ぐため、Markdown 内のリンクは装飾表示のみ行い、自動的な外部ブラウザ起動は行いません。

### リソース枯渇保護
- **50MB ファイルサイズ上限**:
  - 巨大バイナリや極大ファイルの誤オープンによるメモリ枯渇・ハングアップを未然に防止。
- **有界バッファ管理**:
  - AI ストリーミング受信バッファには 1MB の安全上限を設け、Undo/Redo スタックには有界なリングバッファ（`VecDeque`）を採用し、長時間編集セッションにおけるメモリ肥大化を抑えています。
