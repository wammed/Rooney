# ⌨️ Rooney ショートカットキー & 操作ガイド

Rooney のキーボードショートカットおよび操作方法の完全リファレンスです。  
Rooney はキーボード中心の高速なワークフローを重視し、ファイル操作、ペイン分割、AI 支援、コード編集まで直感的なキーバインドを提供しています。

## 1. ファイル & タブ操作

| ショートカット | 動作 | 詳細 |
| :--- | :--- | :--- |
| `Ctrl + N` | **新規ファイル作成** | ファイル名入力モーダルを表示し、ワークスペース内に新規作成 |
| `Ctrl + O` | **ファイルを開く** | XDG Desktop Portal ネイティブファイル選択ダイアログを開く |
| `Ctrl + Shift + O` | **フォルダを開く** | ワークスペースフォルダを選択し、ファイルツリーを切り替え |
| `Ctrl + S` | **ファイルを保存** | 一時ファイル置換（Atomic Write）による安全保存 |
| `Ctrl + Shift + S` | **名前を付けて保存...** | 新しいファイル名を指定して保存し、言語解析を自動更新 |
| `Ctrl + T` | **新規タブ作成** | 空の無題タブ（Untitled）を作成 |
| `Ctrl + W` | **アクティブタブを閉じる** | 現在選択中のタブを閉じる |
| `Ctrl + Tab` | **次のタブへ移動** | タブバーを右方向へ巡回 |
| `Ctrl + Shift + Tab` | **前のタブへ移動** | タブバーを左方向へ巡回 |

## 2. ウィンドウ & ペインレイアウト

| ショートカット | 動作 | 詳細 |
| :--- | :--- | :--- |
| `Ctrl + \` または `Ctrl + E` | **2分割ペイン切り替え** | 画面を左右 2 分割（Split View）または単一ペイン（Single View）にトグル |
| `Ctrl + B` | **サイドバー開閉** | 左側のファイルツリーエクスプローラーの表示 / 非表示をトグル |
| `Ctrl + ,` | **Aesthetics 設定** | 外観設定モーダル（テーマ、透明度、フォント、AIモデル、GFM切替）を開く |
| `Esc` | **キャンセル / 閉じる** | 開いている検索バー、各種モーダル、コンテキストメニューを閉じる |

## 3. エディタ編集 & カーソル操作

| ショートカット | 動作 | 詳細 |
| :--- | :--- | :--- |
| `Ctrl + Z` | **元に戻す (Undo)** | 直前の編集操作を取り消す |
| `Ctrl + Y` / `Ctrl + Shift + Z` | **やり直し (Redo)** | 取り消した操作を再適用する |
| `Ctrl + A` | **全選択** | バッファ全体のテキストを選択 |
| `Ctrl + C` | **コピー** | 選択テキスト（未選択時は行全体）をクリップボードにコピー |
| `Ctrl + X` | **切り取り** | 選択テキスト（未選択時は行全体）を切り取り |
| `Ctrl + V` | **貼り付け** | クリップボードのテキストをカーソル位置に挿入 |
| `Ctrl + /` | **行コメントのトグル** | 編集中の言語シンタックスに応じたコメント記号の付与 / 解除 |
| `Ctrl + D` | **現在行の複製** | カーソルのある行を直下にそのまま複製 |
| `Ctrl + Shift + K` | **現在行の丸ごと削除** | カーソルのある行を削除して行を詰める |
| `Tab` | **インデント挿入** | スペースまたはタブを挿入（選択範囲がある場合は行全体をインデント） |
| `Shift + Tab` | **インデント解除** | 先頭のインデントを解除（アンインデント） |
| `Home` / `End` | **行頭 / 行末移動** | 現在行の先頭または末尾へカーソル移動 |
| `Ctrl + Home` / `Ctrl + End` | **ファイル先頭 / 末尾移動** | バッファ全体の先頭または末尾へ移動 |
| `PageUp` / `PageDown` | **ページスクロール** | 画面単位で高速スクロール |

## 4. 検索 & ナビゲーション

| ショートカット | 動作 | 詳細 |
| :--- | :--- | :--- |
| `Ctrl + F` | **ファイル内検索バー開閉** | エディタ下部にインクリメンタル検索バーを表示 |
| `Enter` (検索バー内) | **次の一致箇所へ移動** | 検索文字列に一致する次の箇所へフォーカスジャンプ |
| `Shift + Enter` (検索バー内) | **前の一致箇所へ移動** | 検索文字列に一致する前の一致箇所へフォーカスジャンプ |
| `Esc` (検索バー内) | **検索終了** | 検索バーを閉じてエディタキャンバスへフォーカスを復帰 |

## 5. Markdown プレビュー操作

| ショートカット | 動作 | 詳細 |
| :--- | :--- | :--- |
| `Ctrl + M` | **Markdown プレビュー切替** | 右ペインに GFM / CommonMark リアルタイムレンダリングを表示 |
| 設定モーダル内 | **Markdown 仕様切替** | **GFM**（テーブル・アラート・タスクリスト対応）と **CommonMark** を動的切替 |

※ Markdown プレビューは **Zero Remote I/O（外部ネットワーク通信なし）** 設計となっており、画像の外部フェッチやスクリプト実行は安全に遮断されます。

## 6. ローカル AI 支援機能

| ショートカット | 動作 | 詳細 |
| :--- | :--- | :--- |
| `Ctrl + I` または `Alt + Enter` | **FIM インライン補完** | カーソル位置のコンテキストから Fill-in-the-Middle ゴースト補完を生成 |
| `Tab` (補完表示時) | **ゴースト補完の確定** | 提案されたコードを受け入れてエディタに挿入 |
| `Esc` (補完表示時) | **補完のキャンセル** | 提案中のゴーストテキストを破棄 |
| `Ctrl + Shift + A` | **AI チャットパネル開閉** | 右側にストリーミング対話型ローカル AI チャットを開く |

---

## 7. 設定 & ダイアログ操作

- **テーマ & 透明度設定**: `Ctrl + ,` でモーダルを開き、20種類のテーマ（Tokyo Night, Catppuccin, Gruvbox 等）、エディタ・ツリー・タイトルバーの各部独立透明度、背景ディミング、AI モデルを直感的に設定できます。
- **ファイルツリー操作**: マウス右クリックで「新規ファイル」「新規フォルダ」「リネーム」「安全削除」のコンテキストメニューが表示されます。
